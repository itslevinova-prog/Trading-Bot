# Original recorded-support exit research

A separately versioned research provider composes the existing covariance/rolling-structure policy. It preserves existing exits and entries, adding an optional full exit only for a uniquely held, owned, single-origin, correctly scoped trend entry with actually captured original support. After entry, a new closed signal must close below that original support, below current EMA20, with negative1h momentum. Legacy/unknown/compound entries, source/position/quantity/scope mismatches and stale/currently unclosed observations cannot invent an extra exit. This is a NEW stated exit hypothesis; it is not a claim that the old strategy originally promised that support as its exit intent.

The runtime source interpreter and evidence summary are now pure shared helpers. The replay has an optional synchronous confirmed-buy observer after actual simulated risk-approved fills, receiving isolated copies. The original context is copied before provider execution; complete original actions are supplied, including duplicates. Source order/fill/decision/evidence identities are bound. Rejected proposals do not generate entry origins. Historical capture/receipt clocks remain explicitly modelled and separate from actual report materialization. Nothing is backfilled into the frozen prospective V3.

An initial comparison used a selected-action-only observer. Review identified that this could hide duplicate buy proposals. Protocolv2 corrects that method and adds a duplicate-source regression.
