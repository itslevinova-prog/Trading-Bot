# Native public activity capture (Paper only)

The main process now optionally records final 15-minute messages from its existing Binance public WebSocket subscriptions. This supplies prospective quote-volume, exchange trade counts and taker-buy volume with original messages and actual local receipt times. It does not change entry/exit rules or activate learning. Market trade counts are not bot trades or independent samples.

Enable through the existing guarded local launcher with `node scripts/resume-main-paper.mjs --capture-public-activity`, only after its existing stopped-process/port checks. Direct startup reads `PAPER_PUBLIC_ACTIVITY_CAPTURE=true`. Omitted flag defaults off. Do not restart a live process merely to repeat this command. Normal feed bootstrap on restart still uses its existing public endpoints; capture itself introduces no additional market subscription or request.

Storage is fixed to `data/public-ws-activity/binance-<QUOTE>.db`, separate from the application database. Verified free Paper runtime, no remote/model calls, and non-experiment main identity are required. Ownership marker binds canonical project root and quote. Unowned application/fixture databases, copied project journals, archive roots, symlinks, hard links and main-database/SQLite-companion collisions fail closed. Initialization is atomic. Write contention does not block waiting for the journal lock; disk failures are isolated from the ordinary feed and protective exits. Missing records remain unknown. Shutdown closes the separate journal.

A session binds run/build/start/transport/producer; append-only links prevent retroactively relabelling old records. These hashes establish local integrity, not cryptographic exchange authentication. The journal preserves the full native payload and receipt, semantic facts and raw hashes. Actual 1h/4h/24h readers require 4/16/96 contiguous current closed bars, source OHLCV matches and as-of availability. No REST backfill can reconstruct first receipt; fixture eligibility tests are not real captures. Compatible sessions survive restart. Earlier missing bars stay missing.
