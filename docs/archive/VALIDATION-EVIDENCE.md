# Clock-level validation evidence and decision sensitivity

The unchanged 41-fold research uses 160 validation asset rows per fold, but these represent only eight market clocks over four days across 20 assets. Eight distinct clocks are not eight independent samples. Cross-asset and serial dependence have not been estimated. No confidence level, future win probability or effective independent sample size is established.

The preregistered validation protocol v1 reconstructs all 6,560 validation rows and 32,800 forecasts from the frozen model requests/outputs. Original selectors and MAE metrics reproduce exactly; labels must mature strictly before the test boundary. Eleven new helper tests plus eight existing ranking tests pass; server/test typechecks and build pass. Independent Python verifies every forecast, 328 leave-one-clock-out cases and 1,640 validation opportunity choices. Canonical report: validation-evidence-audit-2c25cb174c52fdce.json; proof: validation-evidence-independent.json.

Removing all 20 asset rows of one validation clock changes the selected model name in 44 of 328 cases, across 21 of 41 folds. These are frozen-prediction sensitivity checks, not retraining, bootstrap confidence intervals, independent experiments or a replacement selector. Of nine folds selecting a slope-fitted ridge-family model, three have no validation opportunity above the unchanged 0.005 entry margin. Whole-row MAE alone therefore does not demonstrate sufficient evidence about the sparse entry decisions. The training mean is numerical too; the report's numericSelectedFolds field specifically means ridge/common/aggressor.

A second preregistered, explicitly exploratory behavior audit distinguishes model names from candidate decisions. It compares existing candidate-or-NO-TRADE keys without reading test payoffs. Only nine of the 44 mode changes alter test decisions, across seven folds. Nineteen of 2,624 repeated clock comparisons change, representing 15 unique test clocks. These comparisons overlap and are not 2,624 independent trials. Independent Python verifies all 328 cases and 2,624 comparisons. Report: validation-behavior-audit-c5b7ab4d63adbdd7.json; proof: validation-behavior-independent.json. It would overstate the result to describe every mode-name change as a changed trade or a loss.
