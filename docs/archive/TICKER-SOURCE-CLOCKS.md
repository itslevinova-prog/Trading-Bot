# Source-specific ticker receipt clocks

A real context gap was confirmed in the existing public feed: Binance book updates advanced a single receivedAt while retaining earlier last/volume/change24h values. Kraken partial ticker updates also refreshed the shared timestamp for omitted fields. Closed-candle indicators already derive returns from closed bars, not these ticker statistics; this change is context fidelity rather than a new entry strategy or a profit result.

MarketTicker now optionally carries fieldReceivedAt for bid, ask, last, volume and change24h. The public Paper-feed handlers update only valid fields actually present. Zero volume and zero/negative changes are valid observations. Missing, nonfinite and invalid price/volume updates do not refresh a clock; an earlier local receipt cannot overwrite a later known field. Quote-only updates do not create a midpoint masquerading as an observed last trade. Carried legacy values retain unknown per-field clocks. Existing receivedAt becomes the older bid/ask receipt when both are known; it is a quote clock, not a statistics clock.

The initial Binance REST ticker receipt is captured when that public request completes, before waiting for independent exchange metadata or writing pair selections. A tested slow-metadata scenario retains receipt1000 even though pair selection finishes5000. Binance streaming quotes still come from the validated book. Kraken partial observations retain omitted-field provenance.

Annotated marketContext.quality.tickerAgeMs conservatively reports the oldest of all five observed field ages, or null if any is unknown, future-dated or invalid. Raw per-field receipt clocks remain in the ticker itself, so callers can calculate each age without duplicated age lists. Legacy snapshots keep their existing coarse age shape; no per-field freshness is inferred. These are LOCAL RECEIPT clocks, not exchange event age, proof that a price did not change, or a forecast. Clock skew/network delay are not estimated. Execution/valuation still require their own valid, timely order book. No fee, stop, protective-exit, sizing or trading-policy threshold changed.
